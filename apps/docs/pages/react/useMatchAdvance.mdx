# useMatchAdvance

## Usage

```tsx twoslash
import { useMatchAdvance } from "@cartesi/react";

function Example() {
  const { data, isLoading } = useMatchAdvance({
    application: "0x...",
    epochIndex: 1n,
    tournamentAddress: "0x...",
    idHash: "0x...",
    txHash: "0x...",
    logIndex: 0n,
  });
  // render logic
}
```

## Return Type

The `data` is an `MatchAdvanced`:

```ts twoslash
import {
  type MatchAdvanced,
  type GetMatchAdvanceReturnType,
} from "@cartesi/client";
```
