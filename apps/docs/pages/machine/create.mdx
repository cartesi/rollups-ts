# create

Creates a new local Cartesi machine instance from the given configuration and optional runtime configuration. Returns a [CartesiMachine](/machine/CartesiMachine) instance. This is the main entry point for instantiating a new machine in your application.

## Function Signature

```ts
create(config: MachineConfig, runtimeConfig?: MachineRuntimeConfig, dir?: string, sharing?: SharingMode): CartesiMachine
```

With `dir`, the machine is created on disk: the result is the same as creating it in memory, storing it to `dir` and loading it back with `sharing`, which defaults to `SharingMode.All` (every change goes to the directory). See [CartesiMachine.create](/machine/CartesiMachine#create).

## Example

```ts twoslash
import { create, BreakReason } from "@cartesi/machine";

const machine = create({
    ram: {
        length: 0x8000000, // 128MB of RAM
        backing_store: { data_filename: "linux.bin" },
    },
    flash_drive: [
        {
            backing_store: { data_filename: "rootfs.ext2" },
        },
    ],
    dtb: {
        entrypoint: "echo Hello world!",
    },
});

// Run the machine until it yields or halts (default is MAX_MCYCLE)
const reason = machine.run();
if (reason === BreakReason.Halted) {
    console.log("Machine halted");
}
```
