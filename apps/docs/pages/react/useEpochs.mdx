# useEpochs

## Usage

```tsx twoslash
import { useEpochs } from "@cartesi/react";

function Example() {
  const { data, isLoading } = useEpochs({
    application: "0x...",
    limit: 50,
    offset: 0,
    // ...other filters
  });
  const { data: epochs, pagination } = data || {};
  // render logic
}
```

## Filters

The hook can filter results by:

- `application: Address | string`
- `status?: EpochStatus | NonEmptyArray<EpochStatus>` — an empty list is not a
  valid filter, and does not compile
- `from?: bigint` — inclusive lower bound on the epoch index
- `to?: bigint` — inclusive upper bound on the epoch index

```ts twoslash
import type {
  EpochStatus,
  ListEpochsParams,
} from "@cartesi/client";
```

## Return Type

The `data` is an array of `Epoch`:

```ts twoslash
import type {
  Epoch,
  ListEpochsReturnType,
  Pagination,
} from "@cartesi/client";
```

For more information about pagination refer to the [pagination section](/react#index).
