# listBondEvents

## Usage

```ts twoslash
import { http } from "viem";
import { createCartesiPublicClient } from "@cartesi/client";

const publicClientL2 = createCartesiPublicClient({
  transport: http("http://127.0.0.1:6751/rpc"),
});

const { data, pagination } = await publicClientL2.listBondEvents({
  application: "0x...",
  limit: 10,
  offset: 0,
});
```

Events are ordered by block number and block-global log index; `descending`
reverses both.

`BondEvent` is discriminated on `type`, so narrow before reading the payload:

```ts twoslash
import type { BondEvent } from "@cartesi/client";
// ---cut---
declare const bondEvent: BondEvent;

if (bondEvent.type === "PARTIAL_BOND_REFUND") {
  // the value that was requested, paid only if `success`
  bondEvent.refund.value;
} else {
  bondEvent.recovery.payment;
}
```
