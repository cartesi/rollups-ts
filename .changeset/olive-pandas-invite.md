Add `@cartesi/rollup`, Node.js bindings for libcmt (the Cartesi Machine guest rollup library), imported from `@deroll/cmio`. Lets applications running inside a Cartesi Machine handle advance/inspect requests and emit vouchers, notices, reports and exceptions without the rollup HTTP server. Documented under `/rollup` in the docs site.
