# useMatchAdvanced

## Usage

```tsx twoslash
import { useMatchAdvanced } from "@cartesi/react";

function Example() {
  const { data, isLoading } = useMatchAdvanced({
    application: "0x...",
    epochIndex: 1n,
    tournamentAddress: "0x...",
    idHash: "0x...",
    parent: "0x...",
  });
  // render logic
}
```

## Return Type

The `data` is an `MatchAdvanced`:

```ts twoslash
import {
  type MatchAdvanced,
  type GetMatchAdvancedReturnType,
} from "@cartesi/viem";
```
