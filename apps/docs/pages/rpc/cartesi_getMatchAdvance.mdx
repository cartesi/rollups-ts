# cartesi_getMatchAdvance

## Usage

```ts twoslash
// [!include ~/snippets/rpc/createClient.ts]

const { data: matchAdvanced } = await client.request("cartesi_getMatchAdvance", {
    application: "0x0974CC873dF893B302f6be7ecf4F9D4b1A15C366",
    epoch_index: "0x2A",
    tournament_address: "0x0974CC873dF893B302f6be7ecf4F9D4b1A15C366",
    id_hash: "0x0974CC873dF893B302f6be7ecf4F9D4b1A15C366",
    tx_hash: "0x0974CC873dF893B302f6be7ecf4F9D4b1A15C366",
    log_index: "0x0",
});
```

An advance is keyed by the transaction hash and block-global log index of its
event, both of which `cartesi_listMatchAdvances` returns: repeated other-parent
hashes stay distinct events, so the parent hash alone does not identify one. A
log index of zero is valid.

## Return Type

```ts twoslash
import { type MatchAdvanced } from "@cartesi/rpc";
```
