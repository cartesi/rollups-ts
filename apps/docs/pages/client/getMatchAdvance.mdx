# getMatchAdvance

## Usage

```ts twoslash
import { http } from "viem";
import { createCartesiPublicClient } from "@cartesi/client";

const publicClientL2 = createCartesiPublicClient({
  transport: http("http://127.0.0.1:6751/rpc"),
});

const matchAdvance = await publicClientL2.getMatchAdvance({
  application: "0x...",
  epochIndex: 1n,
  tournamentAddress: "0x...",
  idHash: "0x...",
  txHash: "0x...",
  logIndex: 0n,
});
```

An advance is keyed by the transaction hash and block-global log index of its
event, both of which `listMatchAdvances` returns: repeated other-parent hashes
stay distinct events, so the parent hash alone does not identify one. A log
index of zero is valid.
