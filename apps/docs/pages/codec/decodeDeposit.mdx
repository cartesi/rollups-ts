# decodeDeposit

Decodes the payload of an input as a portal deposit, dispatching on the input's `msgSender`: if it is one of the portal deployment addresses, the payload is decoded with the corresponding decode function ([decodeEtherDeposit](/codec/decodeEtherDeposit), [decodeERC20Deposit](/codec/decodeERC20Deposit), [decodeERC721Deposit](/codec/decodeERC721Deposit), [decodeERC1155SingleDeposit](/codec/decodeERC1155SingleDeposit) or [decodeERC1155BatchDeposit](/codec/decodeERC1155BatchDeposit)).

The portal deployment addresses come from the same pinned rollups-contracts release as the ABIs, and are also exported (`etherPortalAddress`, `erc20PortalAddress`, `erc721PortalAddress`, `erc1155SinglePortalAddress`, `erc1155BatchPortalAddress`).

## Usage

```ts twoslash
import { decodeDeposit, decodeInput } from "@cartesi/codec";

const input = decodeInput("0x...");
const deposit = decodeDeposit(input);

if (deposit) {
  switch (deposit.type) {
    case "EtherDeposit":
      console.log(deposit.sender, deposit.value);
      break;
    case "ERC20Deposit":
      console.log(deposit.token, deposit.sender, deposit.value);
      break;
    case "ERC721Deposit":
      console.log(deposit.token, deposit.sender, deposit.tokenId);
      break;
    case "ERC1155SingleDeposit":
      console.log(deposit.token, deposit.tokenId, deposit.value);
      break;
    case "ERC1155BatchDeposit":
      console.log(deposit.token, deposit.tokenIds, deposit.values);
      break;
  }
} else {
  // not a deposit: a regular input sent by `input.msgSender`
}
```

## Parameters

- `input`: a decoded input — only the `msgSender` and `payload` fields are used.

## Return Type

A `Deposit` union discriminated by the `type` field (`"EtherDeposit"`, `"ERC20Deposit"`, `"ERC721Deposit"`, `"ERC1155SingleDeposit"` or `"ERC1155BatchDeposit"`), where each variant carries the fields of the corresponding deposit type.

Returns `undefined` if `msgSender` is not a portal, i.e. the input is not a deposit.

## Errors

Throws if `msgSender` is a portal but the payload is malformed.
