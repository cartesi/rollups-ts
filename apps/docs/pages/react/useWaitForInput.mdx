# useWaitForInput

## Usage

```tsx twoslash
import { useWaitForInput } from "@cartesi/react";

function Example() {
  const { data, isLoading } = useWaitForInput({
    application: "0x...",
    inputIndex: 2n,
    // ...other wait options
  });
  // render logic
}
```

## Return Type

The `data` is an `Input` (resolved when the input is processed):

```ts twoslash
import type { GetInputReturnType } from "@cartesi/client";
```

The wait options are the ones [`waitForInput`](/client/waitForInput) takes.
`waitProcessing` (default `true`) polls while the input is still `NONE`, and
`rejectErrors` (default `false`) fails the query once the input reaches any
terminal status other than `ACCEPTED` — `REJECTED`, `EXCEPTION`,
`MACHINE_HALTED`, `OVERFLOW` or `UNEXPECTED_YIELD` — so the hook surfaces it
through `error` rather than `data`.
