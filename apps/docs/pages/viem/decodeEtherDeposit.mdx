# decodeEtherDeposit

Decode an `EtherPortal` deposit input payload: `sender` (20 bytes) + `value` (32 bytes) + `execLayerData`.

Throws `InvalidDepositPayloadError` if the payload is shorter than 52 bytes.

## Usage

```ts twoslash
import { decodeEtherDeposit } from "@cartesi/viem/portal";

const deposit = decodeEtherDeposit(
    "0xf39fd6e51aad88f6f4ce6ab8827279cfffb922660000000000000000000000000000000000000000000000000de0b6b3a7640000deadbeef",
);
// {
//   type: "EtherDeposit",
//   sender: "0xf39Fd6e51aad88F6F4ce6aB8827279cffFb92266",
//   value: 1000000000000000000n,
//   execLayerData: "0xdeadbeef",
// }
```

## Parameters

```ts twoslash
// payload: Hex — the deposit input payload produced by the EtherPortal
```
