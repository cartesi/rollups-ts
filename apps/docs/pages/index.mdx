# Cartesi TypeScript libraries

A set of libraries for building [Cartesi](https://cartesi.io) applications in TypeScript — from the code that runs *inside* the Cartesi Machine to the frontend that talks to a Cartesi node.

Pick the layer you are working on:

## Frontend

Talk to a Cartesi node and to the rollups contracts on the base layer.

### [@cartesi/client](/client)

A [viem](https://viem.sh) extension. L2 public actions for the Cartesi Rollups node [JSON-RPC API](https://playground.open-rpc.org/?schemaUrl=https://raw.githubusercontent.com/cartesi/rollups-node/refs/tags/v2.0.0-alpha.10/internal/jsonrpc/jsonrpc-discover.json&uiSchema[appBar][ui:title]=Cartesi&uiSchema[appBar][ui:logoUrl]=https://cartesi.io/favicon.svg&uiSchema[appBar][ui:transports]=false&uiSchema[appBar][ui:input]=false&uiSchema[appBar][ui:edit]=false&uiSchema[appBar][ui:examplesDropdown]=false&uiSchema[appBar][ui:splitView]=false) — read inputs, outputs, reports and epochs — plus the typed ABIs and deployment addresses for [L1 contract interactions](/client/l1).

**Start with** [the introduction](/client), or jump to [`getInput`](/client/getInput) · [`listOutputs`](/client/listOutputs) · [`waitForInput`](/client/waitForInput).

### [@cartesi/react](/react)

The same L2 actions as React hooks, built on [TanStack Query](https://tanstack.com/query): [`useInput`](/react/useInput), [`useOutputs`](/react/useOutputs), [`useWaitForInput`](/react/useWaitForInput) and one per action.

**Start with** [the introduction](/react).

### [@cartesi/rpc](/rpc)

The typed JSON-RPC client underneath `@cartesi/client`. Use it directly when you want the raw `cartesi_*` methods and wire types rather than viem.

**Start with** [the introduction](/rpc), or see [`createClient`](/rpc/createClient).

## Bindings

Native addons for the Cartesi Machine. Prebuilt binaries ship for linux and macOS, so there is nothing to compile.

### [@cartesi/rollup](/rollup)

Bindings for [libcmt](https://github.com/cartesi/machine-guest-tools/tree/main/sys-utils/libcmt), the guest rollup library, for applications running **inside** a Cartesi Machine: handle advance and inspect requests and emit vouchers, notices, reports and exceptions, without the rollup HTTP server. The same code runs on your development host against a mock.

**Start with** [Getting Started](/rollup/getting-started), then [Handling Requests](/rollup/handling-requests).

### [@cartesi/machine](/machine)

Bindings for the [Cartesi Machine emulator](https://github.com/cartesi/machine-emulator) itself, for code running **outside** the machine: create, run, snapshot and inspect machines [in-process](/machine/local) or [out-of-process](/machine/remote) over JSON-RPC, and drive a [rollups machine](/machine/rollups-machines) through advance and inspect requests.

**Start with** [the introduction](/machine), then [Local Machine](/machine/local).

## Encoding

### [@cartesi/codec](/codec)

Isomorphic encoding and decoding of the blobs that cross the machine boundary: inputs ([`EvmAdvance`](/codec/decodeInput)), outputs ([`Notice`, `Voucher`, `DelegateCallVoucher`](/codec/decodeOutput)) and [portal deposits](/codec/decodeDeposit). Browser and Node.js, depends only on viem.

**Start with** [the introduction](/codec).

## Codegen

### [@cartesi/wagmi-plugin](/wagmi-plugin)

A [Wagmi CLI](https://wagmi.sh/cli/getting-started) plugin that generates ABIs and deployment addresses for the [Cartesi Rollups contracts](https://github.com/cartesi/rollups-contracts) straight from an official release.

**Start with** [the introduction](/wagmi-plugin).
