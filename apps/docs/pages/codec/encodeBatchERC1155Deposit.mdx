# encodeBatchERC1155Deposit

Encodes an ERC-1155 batch deposit payload as the ERC-1155 batch portal does. This is the inverse of [decodeBatchERC1155Deposit](/codec/decodeBatchERC1155Deposit), useful for testing.

## Usage

```ts twoslash
import { encodeBatchERC1155Deposit } from "@cartesi/codec";

const payload = encodeBatchERC1155Deposit({
  token: "0x67742ff5b2b762503ff0a92738c6fc2ea4a4d182",
  sender: "0x92cc14432c1f82622493abd64d99ea8a3000a7c7",
  tokenIds: [1n, 2n, 3n],
  values: [100n, 200n, 300n],
  baseLayerData: "0x",
  execLayerData: "0xdeadbeef",
});
```

## Parameters

A `BatchERC1155Deposit` object:

- `token` (`Address`): token contract.
- `sender` (`Address`): token sender.
- `tokenIds` (`readonly bigint[]`): identifiers of the tokens being transferred.
- `values` (`readonly bigint[]`): transfer amounts per token type.
- `baseLayerData` (`Hex`): additional data to be interpreted by the base layer.
- `execLayerData` (`Hex`): additional data to be interpreted by the execution layer.

## Return Type

`Hex`: packed-encoded deposit payload, with layout `token (20 bytes) ‖ sender (20 bytes) ‖ abi.encode(tokenIds, values, baseLayerData, execLayerData)`.
